Projects

Things I've built. Source code linked where available.

  1. SOFTWARE
    1. I HashCatch, a Document Similarity Engine

      Plagiarism detection built entirely from scratch in C++, without STL. Implements a polynomial rolling hash and a custom open-addressing hash table with linear probing for O(1) word lookup. Applies Jaccard similarity across two hash tables to produce a document similarity percentage. CLI tool accepting any two text files.

      c++ hash tables algorithms cli
    2. II Logged Retrieval-Augmented Generation System

      Production-style RAG pipeline combining ChromaDB vector storage with Gemini embeddings for semantic search over large document corpora. Hybrid retrieval blends semantic similarity with keyword matching. Confidence scoring and structured logging make retrieval decisions auditable.

      python chromadb gemini rag vector search
    3. III NephroCare, a Predictive Healthcare Support System

      Machine learning system for early detection and monitoring of chronic kidney disease, addressing a condition affecting 1 in 7 Americans. Feature engineering pipeline for clinical biomarkers using Pandas and NumPy; supervised learning models evaluated with k-fold cross-validation. Modular analytics components targeting a 15–30% reduction in missed appointments.

      python scikit-learn pandas numpy healthcare
